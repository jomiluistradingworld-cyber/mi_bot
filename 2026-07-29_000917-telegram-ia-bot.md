# Telegram Conversational Bot with Personality Profiles Implementation Plan

> **For Hermes:** Use subagent‑driven‑development skill to implement this plan task‑by‑task.

**Goal:** Provide an open‑source, Telegram‑based conversational bot that lets users pick from predefined personality profiles (e.g., "mentor espiritual", "amigo incondicional", "estratega"), supports adding new profiles, and runs entirely on the user’s laptop using local models hosted via Ollama or llama.cpp, eliminating dependency on paid APIs.

**Architecture:**
- **Bot Core:** Telegram Bot API via python-telegram-bot.
- **Dialogue Engine:** Local LLM inference wrapped in a simple API; toggles between Ollama and llama.cpp.
- **Personality Management:** JSON‑based profile files with configurable persona, tone, and custom prompts.
- **Logging & Telemetry:** Structured JSON logs written to a rolling file, plus optional console output.
- **Deployment:** Pure Python repo; optional Docker for reproducible environment.

**Tech Stack:**
- Python 3.11+ (venv)
- [python‑telegram‑bot](https://python-telegram-bot.org/)
- [ollama](https://ollama.ai/) or [llama.cpp](https://github.com/ggerganov/llama.cpp) integration
- [loguru](https://github.com/polakowo/loguru) for logging
- [pytest](https://docs.pytest.org/) for tests
- Git for version control; GitHub repository for hosting and CI

In `bot/telegram_bot.py`:

```python
import os
from telegram.ext import Updater, MessageHandler, Filters
from loguru import logger

BOT_TOKEN = os.getenv("TELEGRAM_BOT_TOKEN")


def echo(update, context):
    context.bot.send_message(chat_id=update.effective_chat.id, text=update.message.text)


def start_bot():
    if not BOT_TOKEN:
        raise ValueError("TELEGRAM_BOT_TOKEN not set")
    updater = Updater(token=BOT_TOKEN, use_context=True)
    dispatcher = updater.dispatcher
    dispatcher.add_handler(MessageHandler(Filters.text & ~Filters.command, echo))
    updater.start_polling()
    updater.idle()
```

**Step 4: Run test to verify pass**

`pytest tests/test_telegram_bot.py::test_bot_echo -v`

### Task 5: Connect Bot to LLM and Personality Excerpts

**Objective:** When a user selects a personality, store session context and produce replies via the chosen LLM.

**Files:**
- Update: `bot/telegram_bot.py` – add commands `/start`, `/profile`, `/addprofile`.
- Update: `bot/personality.py` – add method to merge system_prompt and user message.
- Update: `bot/llm.py` – instantiate selected LLM.

**Step‑by‑step:**
1. `/profile <name>` command queries `profiles/` directory for matching JSON.
2. Store selected profile in memory per chat.
3. Build prompt: `profile.system_prompt +\nUser: <msg>\nAssistant:`.
4. Pass to `LLMClient.generate()`.
5. Send returned text.

**Verify:** Send a test message with `/profile mentor-espiritual` and confirm echo.
